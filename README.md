# English Master · 영어 마스터

바쁜 사람을 위한 **하루 10분 회화** 앱 (홈 화면 설치·오프라인 실행).

## 하루 10분 루틴
1. **복습** — 한국어를 보고 영어로 소리 내 말하기 → 정답 듣기 → "말했어요 / 헷갈렸어요". 간격 반복(1·3·7·14·30·60일)으로 오늘 볼 것만 나옴 (하루 최대 15개)
2. **새 대화** — ① 들어 보기 ② 한 줄씩 따라 말하기 ③ 내 역할을 보지 않고 말하기
3. **내 문장 만들기** — 오늘의 문장 틀에 내 이야기를 넣어 말하기

- 🎧 듣기만 하기: 한국어 → 생각할 틈 → 영어 두 번 (출퇴근길용)
- 🎤 말하기 확인: 브라우저 음성 인식으로 들린 문장이 맞는지 표시 (발음 점수 아님)
- 코스: 여행 10 · 일상 8 · 영업 8 · 숙박 운영 8 (첫 화면에서 '이 코스로'를 누르면 그 코스부터)
- 새 버전은 앱을 열 때 자동 반영 (version.json)

## 구조
- `talk.js` 엔진 (영어·일본어 공용) / `course-en.js` 내용 / `sw.js` 네트워크 우선 캐시
- 고칠 때: `index.html`의 `APP_V`와 스크립트 주소 뒤 `?v=`, `version.json`, `sw.js`의 CACHE 숫자를 같이 올림

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).
